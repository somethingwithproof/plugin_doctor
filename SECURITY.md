# Security Policy

## Supported Versions

Security fixes land on the `develop` branch.

## Reporting a Vulnerability

Do not report vulnerabilities in public issues or pull requests.

Report them privately through [GitHub private vulnerability reporting](https://github.com/somethingwithproof/plugin_doctor/security/advisories/new), or by email to thomasvincent@gmail.com.

Include the affected version, the Cacti and PHP versions, steps to reproduce, and the impact you observed. You should get an acknowledgement within a few days.

Doctor runs inside Cacti with the privileges of the web server or poller user. Reports about Cacti itself belong in the [Cacti security policy](https://github.com/Cacti/cacti/security/policy).
